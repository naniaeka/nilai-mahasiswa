# Sistem Pengelolaan Nilai Mahasiswa

Aplikasi web sederhana untuk input nilai, perhitungan nilai akhir, dan rekapitulasi hasil.

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka file `index.html` dengan browser (Chrome atau Edge). Tidak perlu instalasi.

## Aturan nilai
- Nilai Akhir = 30% Tugas + 30% UTS + 40% UAS
- Huruf: A (>= 85), B (>= 70), C (>= 55), D (>= 40), E (< 40)
- Lulus jika Nilai Akhir >= 55

## Fitur
Tambah, ubah, hapus, dan cari data; validasi input; rekap (jumlah, rata-rata, tertinggi, terendah, lulus, distribusi huruf); data tersimpan di localStorage browser.

## Teknologi
HTML, CSS, JavaScript murni.
