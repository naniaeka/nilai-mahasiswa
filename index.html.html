Sistem Pengelolaan Nilai Mahasiswa

Input nilai, hitung nilai akhir otomatis, dan lihat rekapitulasi hasil. Nilai akhir = 30% Tugas + 30% UTS + 40% UAS. Lulus jika nilai akhir minimal 55.

Input nilai

Angka saja, 8 sampai 12 digit.

Data tersimpan di browser (localStorage).
